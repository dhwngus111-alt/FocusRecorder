# 집중기록기

macOS 메뉴 막대에서 `00:00`부터 목표 시간까지 올라가는 집중 타이머입니다. [Super Easy Timer](https://supereasytimer.com/)의 간결한 사용 흐름을 참고해 독립적으로 만들었습니다. 조작창과 기록 화면은 연보라·연주황·연두색의 겹치는 고리를 모티프로 한 밝고 단순한 디자인입니다. 화면 위 타이머는 배경 없이 흰색 숫자로 표시됩니다.

**바로 설치:** [Apple Silicon용 앱 ZIP](release/FocusRecorder-macOS.zip)을 다운로드하고 압축을 풀어 `FocusRecorder.app`을 응용 프로그램 폴더로 옮긴 뒤 실행하세요.

### 처음 실행할 때 보안 경고가 뜨면

이 배포본은 Apple 개발자 ID로 서명·공증되지 않았습니다. 따라서 macOS에서 **“Apple은 악성 코드가 없음을 확인할 수 없습니다”**라는 경고가 나올 수 있습니다. 이 경고가 나왔다고 앱이 악성 코드로 판정된 것은 아니지만, Apple이 안전성을 확인한 앱도 아닙니다. 출처를 확인한 뒤 실행 여부를 결정하세요.

1. 경고창에서 **완료**를 누릅니다. **휴지통으로 이동**은 누르지 않습니다.
2. **Apple 메뉴 → 시스템 설정 → 개인정보 보호 및 보안**을 열고 아래쪽 **보안** 영역에서 `FocusRecorder`의 **그래도 열기**를 누릅니다. 이 버튼은 앱을 열려고 시도한 뒤 약 1시간 동안 표시됩니다.
3. Mac 로그인 암호로 확인한 다음 다시 나타나는 창에서 **열기**를 누릅니다. 이후에는 보통 두 번 클릭으로 열립니다.

배포 ZIP의 SHA-256: `4fd19a42ba5b31a96f98ebd939881822e6c726da66173410867659fa8a0281f4`

보안 예외를 추가하지 않으려면 아래 **빌드** 절의 명령으로 GitHub 소스에서 직접 앱을 만들 수 있습니다. 전체 Mac 보안 설정을 끄거나 격리 속성을 제거할 필요는 없습니다.

## 사용법

1. 앱을 열면 화면 위쪽 중앙에 `00:00`이 나타나고 Dock에도 앱 아이콘이 표시됩니다. 이 숫자 또는 메뉴 막대의 `00:00`을 클릭합니다.
2. 집중할 시간을 분 단위로 입력하고 **시작**을 누릅니다. 시작하면 조작창이 자동으로 닫히고 화면 타이머만 남습니다. 숫자를 다시 클릭하면 조작창이 열립니다.
3. 목표에 도달하면 자동으로 **성공**으로 기록됩니다. 일찍 끝내면 **실패**로 기록되며 실제 집중 시간도 저장됩니다. 일시정지한 시간은 실제 집중 시간에서 제외됩니다.
4. 타이머를 우클릭하여 **집중 기록 및 설정**을 엽니다. 오늘과 이번 주의 세션당 평균 실제 집중 시간, 달력, 날짜별 모든 기록을 확인할 수 있습니다.
5. 화면 타이머의 흰색 숫자를 **드래그**하여 원하는 위치로 옮길 수 있습니다. 메뉴 막대 높이까지 이동할 수 있고 위치는 다음 실행에도 유지됩니다. 우클릭 메뉴에서 위치를 초기화할 수도 있습니다.
6. 타이머 팝업이나 기록 및 설정 창에서 **화면 타이머 크기**를 조절하고 **항상 다른 창 위에 표시**를 켜거나 끌 수 있습니다. 크기 조절은 메뉴 막대 숫자가 아닌 화면의 타이머에 적용됩니다.

Dock 아이콘을 누르면 타이머 설정 창이 열립니다. 화면 타이머를 우클릭해도 기록 및 설정 메뉴를 열 수 있습니다. 앱을 업데이트할 때는 진행 중인 집중을 마친 후 메뉴 막대 타이머를 우클릭해 **종료**를 선택하고, 기존 앱을 새 버전으로 교체하세요.

화면 타이머, 메뉴 막대 타이머 또는 앱 창을 클릭한 다음 **⌘W 또는 Ctrl+W**를 누르면 화면의 떠 있는 타이머가 사라집니다. 열린 조작창도 닫히지만 앱과 진행 중인 집중은 계속 실행되고 메뉴 막대의 타이머는 남습니다. 다시 보이게 하려면 메뉴 막대 타이머를 클릭해 **화면 표시**를 켜세요. **⌘Q 또는 Ctrl+Q**는 앱 전체를 종료합니다. 화면 타이머를 클릭해 조작창을 열 때는 보고 있던 다른 앱의 화면으로부터 전환하지 않습니다.

기록은 사용자 Mac의 `~/Library/Application Support/FocusRecorder/sessions.json`에만 저장됩니다. 앱을 정상 종료하면 진행 중 세션은 종료 시점의 기록으로 남습니다. 비정상 종료 후 다시 실행하면 마지막으로 저장된 경과 시간까지의 기록이 복구됩니다.

## 빌드

macOS 27과 Apple Command Line Tools가 필요합니다. 현재 제공하는 빌드는 Apple Silicon용입니다.

```sh
./scripts/build.sh
open dist/FocusRecorder.app
```

빌드 결과는 `dist/FocusRecorder.app`입니다. GitHub에서 소스 ZIP을 내려받아 같은 명령으로 빌드할 수 있습니다. 별도 패키지 의존성은 없습니다.
